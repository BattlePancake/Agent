## 2. Core Content

### 2.1 Scope

Анализируемая функциональность: **Авторизация пользователя** по email и паролю для зарегистрированных пользователей системы. Границы анализа ограничены функцией логина и не включают регистрацию, восстановление пароля, выход из системы (logout) и другие смежные функции.

### 2.2 Requirements

| ID | Требование (оригинальный текст) |
| --- | --- |
| REQ-01 | Пользователь может авторизоваться по email и паролю. |
| REQ-02 | Email должен принадлежать зарегистрированному пользователю. |
| REQ-03 | При вводе неправильного пароля система должна отображать сообщение об ошибке. |
| REQ-04 | После нескольких последовательных неуспешных попыток авторизации учетная запись пользователя должна быть временно заблокирована. |
| REQ-05 | После успешной авторизации пользователь должен быть перенаправлен на главную страницу. |
| REQ-06 | Поля Email и Password являются обязательными. |
| REQ-07 | Email должен иметь корректный формат. |
| REQ-08 | Пароль должен соответствовать требованиям безопасности системы. |
| REQ-09 | Заблокированный пользователь не должен иметь возможности авторизоваться. |
| REQ-10 | Система должна обеспечивать безопасную обработку учетных данных пользователя. |
